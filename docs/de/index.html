Installation

Fedora / GNOME (Nautilus 46+, GTK4) — eine Zeile, kein manuelles Klonen:

curl -fsSL https://raw.githubusercontent.com/zonaro/Nautilus-Extensions/main/install.sh | bash

Oder zuerst klonen:

git clone https://github.com/zonaro/Nautilus-Extensions.git
cd Nautilus-Extensions
./install.sh
nautilus -q

🎨 Highlight: Folder Color Revival + unendliche Farben

Der klassische Ordnerfärber, neu aufgelegt für modernes Nautilus — mit unendlichen benutzerdefinierten Farben dank eingebauter NameToColor-Engine (2254 benannte Farben + pt-BR, deterministischer Hash für jedes Wort).

  • Custom color…-Dialog — Namen, Hex oder rgb() eintippen, mit Live-Vorschau des eigenen Theme-Symbols und Farbwähler pro Element.
  • Eine oder zwei Farben (name1;name2) — Rückseite und Vorderseite getrennt eingefärbt; komplexe Theme-Symbole bekommen ein Feld pro Form.
  • Theme-bewusst — entsättigt und färbt das Ordnersymbol des aktuellen Themes (SVG oder PNG); mit Fallback.
  • Vereinheitlicht — die 14 klassischen Farben laufen durch dieselbe Pipeline.
  • Embleme, XDG-Spezialsymbole, Wiederherstellung, Lazy-Theme-Loading.
