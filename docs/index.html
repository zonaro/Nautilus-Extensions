Dual Panel F3

Two panes. One window. Half the clicks.

A complete side-by-side file manager living inside Nautilus. Move files between folders without juggling windows — and it quietly grows new powers as you install the other extensions.

✓Independent views per pane — list or grid, with native sortable columns.
✓Copy & move between panes with a real rsync progress bar, plus drag & drop.
✓Smart integrations — Extract and Video-to-Audio buttons appear only when those extensions are installed and the selection fits.
✓Nautilus-native sidebar with favorites, bookmarks and mounted volumes.

Search & Replace F8

Find and replace across files. With a real preview.

The one tool every file manager forgot. Search file contents with grep or ripgrep, then preview every change as a colored diff before a single byte is written.

✓Live diff preview — old text struck through in red, the replacement in green, line by line.
✓Per-line checkboxes — apply only the occurrences you actually want.
✓Automatic .bak backup of every modified file, so nothing is ever lost.
✓grep or ripgrep, regex or plain text, recursive or current folder.

Archive Browser F7

Open archives without unpacking your patience.

A full replacement for file-roller that browses inside ZIP, 7z, RAR and TAR without extracting first — including the multi-volume archives the others choke on.

✓ZIP, 7z, RAR, TAR, GZ, XZ, ISO and many more, all in one place.
✓Multi-volume 7z and RAR (.001, .002…) handled natively.
✓Password-protected archives, selective extraction, drag & drop.

Get started

One line to a better file manager.

Fedora / GNOME (Nautilus 46+, GTK4) — the install.sh script installs dependencies and every extension, then restarts Nautilus.

Terminal
⋮ − ▢ ✕
# Fedora / GNOME — one line, no manual clone
$ curl -fsSL https://raw.githubusercontent.com/zonaro/Nautilus-Extensions/main/install.sh | bash

# restart is applied automatically (nautilus -q)

Prefer it manual? Clone the repo and copy the .py files plus color_database.json into ~/.local/share/nautilus-python/extensions/, then run nautilus -q.
