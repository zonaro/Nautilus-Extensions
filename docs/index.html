Install

Fedora / GNOME (Nautilus 46+, GTK4) — one line, no manual clone:

curl -fsSL https://raw.githubusercontent.com/zonaro/Nautilus-Extensions/main/install.sh | bash

Or clone first:

git clone https://github.com/zonaro/Nautilus-Extensions.git
cd Nautilus-Extensions
./install.sh
nautilus -q

🎨 Featured: Folder Color Revival + infinite colors

The classic folder colorizer, revived for modern Nautilus — now with infinite custom colors powered by an embedded NameToColor engine (2254 named colors + pt-BR, deterministic hash for any word).

  • Custom color… dialog — type any name, hex or rgb(), with a live preview of your actual theme icon and a color picker per element.
  • One or two colors (name1;name2) — back tab and front flap tinted independently; complex theme icons get one field per shape.
  • Theme-aware — desaturates and tints your current theme's own folder icon (SVG or PNG); falls back gracefully.
  • Built-ins unified — the 14 classic colors go through the exact same pipeline.
  • Emblems, per-XDG special icons, restore-to-default, lazy theme loading.
